# fake-news-detection-charcnn
# Fake News Detection with Character-level CNN

This repository contains the implementation of a fake news detection project
using a Character-level Convolutional Neural Network (CharCNN).

## Project Overview
The goal of this project is to evaluate whether character-level modeling
can effectively detect fake news by learning directly from raw text.

## Datasets
- ISOT Fake News Dataset
- WELFake Dataset (used for cross-dataset evaluation)

## Models
- Baseline: TF-IDF + Logistic Regression
- Advanced Model: Character-level CNN

## Features
- Exploratory Data Analysis (EDA)
- Hyperparameter Optimization (RandomizedSearchCV)
- Model comparison and error analysis

## Files
- `nlp_project.ipynb`: Main Colab notebook containing all experiments

The notebook was developed and executed in Google Colab.
You can upload the notebook to Colab and run all cells sequentially.
